# Ruby从入门到项目实践 - 代码清单

## 关于本书

本书是一本面向零基础读者的 Ruby 与 Rails 实战入门书，采用《Python编程：从入门到实践》验证有效的「语言基础 + 递进项目」两段式结构，副题「语言基础 × 7 个递进项目」，带你从第一行代码走到独立做出可用的命令行工具、数据管理脚本与 Web 应用，收获可直接写进简历的作品集。

全书以 Ruby 3.3+ / Ruby 4.0 为版本基线，贴合 Ruby 官方主推方向。第一部分（第 1—20 章）系统讲透语言基础：开发环境搭建、变量与常量、字符串、数组与哈希、控制流、方法与闭包、正则表达式、文件操作与 IO、错误处理、类与对象、模块与 Mixin、元编程、单元测试与 Gem 管理；第二部分（第 21—40 章）以七个复杂度递进的完整项目落地：Todo CLI → 猜数字游戏 → 联系人管理 → Sinatra 博客 → Rails 社交应用 → 电商 API → 阿里云部署，覆盖从命令行工具到 Web 应用再到云端部署的完整链条。

本书适合零编程基础、想把 Ruby 当作第一门语言的初学者；有 Python、JavaScript、Java 等语言背景、想快速上手 Ruby/Rails 的开发者；想转 Web 开发却不知从何学起的学习者；以及对 Ruby 简洁语法与元编程感兴趣的爱好者。

## 本书特点

**第一，版本最新，体系完整。** 全书锁定 Ruby 3.3+ / Ruby 4.0 版本基线，覆盖从基础语法到 Web 开发与元编程的完整知识图谱，不停留在过时版本。

**第二，递进项目驱动。** 七个递进项目从命令行工具到 Web 应用再到云端部署，难度逐级抬升、成就感持续兑现，读完带走的是可直接写进简历的作品集，告别「学完就忘」。

**第三，决策框架驱动。** Symbol vs String、include vs extend、块与 Proc——本书不只讲语法，更讲每种选择背后的工程理由，让读者在真实项目中做出合理判断。

**第四，代码即文档。** 每个代码文件都对应书中明确标号的「代码清单 N-M」，文件名含章节编号与内容摘要，可在对应章节直接回溯上下文，可读性优先于表演性。

## 代码清单说明

本书所有代码清单均收录于本目录，对应书稿中「代码清单 N-M」标题块。

### 运行环境

```bash
# 环境要求：Ruby 3.3+（本书版本基线 Ruby 3.3+ / Ruby 4.0）
ruby --version
# 运行单个清单文件：清单即独立 Ruby 脚本，克隆本仓后可直接执行
ruby src/代码清单2-1_*.rb
# 项目实战章节（第 21—40 章）依赖第三方 Gem，进入对应项目目录先安装依赖
bundle install
```

### 目录结构

```
src/
├── 代码清单1-* … 代码清单40-*   # 第 1-40 章，共 528 个清单文件（命名「代码清单N-M_ 描述.扩展名」）
└── extracted_code_manifest.json   # 全部清单索引（title/lang/chapter_file/line/extracted_file/source）
```
